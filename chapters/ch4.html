فصل ۱: Dockerfile چیست؟

Dockerfile یک فایل متنی ساده است که مراحل ساخت یک Docker Image را تعریف می‌کند.

Dockerfile فرآیند ساخت Image را کاملاً خودکار و قابل تکرار می‌کند.

نکته

Dockerfile مانند دستور پخت غذا است و Docker Image نتیجه اجرای آن است.

فصل ۲: چرا به Dockerfile نیاز داریم؟

بدون Dockerfile ساخت Image فرآیندی دستی خواهد بود.

مشکلات ساخت دستی Image

  • زمان‌بر بودن نصب نرم‌افزارها
  • فراموش شدن مراحل نصب
  • تفاوت محیط‌های اجرا
  • غیرقابل تکرار بودن Build

مزایای Dockerfile

  • Build کاملاً خودکار
  • قابل نگهداری در Git
  • قابل نسخه‌بندی
  • تکرارپذیر (Repeatable)
  • مناسب برای CI/CD
  • سازگار با همه سیستم‌ها
Best Practice

هیچ‌گاه Imageهای Production را به صورت دستی ایجاد نکنید. همیشه از Dockerfile استفاده کنید.

فصل ۵: محل قرارگیری Dockerfile

معمولاً Dockerfile در ریشه پروژه قرار می‌گیرد. 


Shop.API

│

├── Controllers

├── Services

├── Models

├── Program.cs

├── Shop.API.csproj

└── Dockerfile

نام فایل باید دقیقاً Dockerfile باشد و معمولاً هیچ پسوندی ندارد.

نکته

Docker به صورت پیش‌فرض فایل Dockerfile را در پوشه جاری جستجو می‌کند.

فصل ۶: اولین Dockerfile

یک Dockerfile بسیار ساده: 


FROM nginx

این Dockerfile تنها یک Image بر پایه nginx ایجاد می‌کند.

ساخت Image 

docker build -t my-nginx .
اجرای Container 

docker run -d -p 8080:80 my-nginx
مشاهده Image 

docker images
مشاهده Container 

docker ps

فصل ۷: ساختار کلی Dockerfile

تقریباً تمام Dockerfileها از تعدادی دستور (Instruction) تشکیل شده‌اند. 


FROM

WORKDIR

COPY

RUN

EXPOSE

ENV

CMD

ENTRYPOINT

در فصل‌های بعد هر یک از این دستورات را به صورت کامل بررسی خواهیم کرد.

Lab ۱

گام ۱

یک فایل با نام Dockerfile ایجاد کنید.

گام ۲


FROM nginx

گام ۳

Image را Build کنید. 

docker build -t my-nginx:v1 .

گام ۴

Container را اجرا کنید. 

docker run -d -p 8080:80 my-nginx:v1

گام ۵

Imageها را مشاهده کنید. 

docker images

گام ۶

Containerهای در حال اجرا را مشاهده کنید. 

docker ps
