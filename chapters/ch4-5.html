سؤالات مصاحبه Docker

در این فصل، سؤالات فایل آزمون Docker همراه با پاسخ صحیح و توضیح مفهومی هر پاسخ مرور می‌شوند.

  1. Docker Container چیست؟

    پاسخ صحیح: یک نسخه اجرایی از Docker Image است.

    Image یک الگوی فقط‌خواندنی است و Container نمونه‌ای از آن با یک لایه قابل‌نوشتن است.

  2. Dockerfile چیست؟

    پاسخ صحیح: یک فایل متنی است که دستورهای ساخت Docker Image را تعریف می‌کند.

    Docker Engine دستورهای Dockerfile را به‌ترتیب اجرا می‌کند و لایه‌های Image را می‌سازد.

  3. دستور FROM در Dockerfile چه کاری انجام می‌دهد؟

    پاسخ صحیح: Docker Image پایه را تعیین می‌کند.

    ساخت Image از یک Image پایه آغاز می‌شود و FROM همان نقطه شروع را مشخص می‌کند.

  4. Docker Log Driver چیست؟

    پاسخ صحیح: مکانیزمی برای جمع‌آوری، مدیریت و ارسال Logهای Containerها است.

    Log Driver مقصد خروجی‌های stdout و stderr کانتینر را تعیین می‌کند.

  5. Tagگذاری در Docker به چه معناست؟

    پاسخ صحیح: اختصاص یک نام یا نسخه قابل‌شناسایی به Docker Image است.

    Tag در ساختاری مانند my-api:1.0 نسخه یا نوع Image را مشخص می‌کند.

  6. دستور docker save چه کاری انجام می‌دهد؟

    پاسخ صحیح: یک یا چند Docker Image را در یک آرشیو tar ذخیره می‌کند.

    خروجی docker save با docker load بازیابی می‌شود؛ این دستور مخصوص Image است، نه Container.

  7. Docker Image چگونه ساخته می‌شود؟

    پاسخ صحیح: با دستور docker build ساخته می‌شود.

    این دستور Dockerfile و Build Context را پردازش و Image نهایی را تولید می‌کند.

  8. Docker Container چگونه ایجاد می‌شود؟

    پاسخ صحیح: در میان گزینه‌های سؤال، با دستور docker run ایجاد می‌شود.

    docker run کانتینر را از Image ایجاد و بلافاصله اجرا می‌کند.

  9. دستور CMD در Dockerfile چه کاری انجام می‌دهد؟

    پاسخ صحیح: دستور یا آرگومان پیش‌فرض زمان اجرای Container را تعیین می‌کند.

    CMD در زمان اجرای Container استفاده می‌شود و با آرگومان انتهای docker run قابل بازنویسی است.

  10. برای حذف Docker Image از چه دستوری استفاده می‌شود؟

    پاسخ صحیح: دستور docker rmi.

    docker rmi image-name Image را حذف می‌کند؛ docker rm مخصوص Container است.

  11. برای کپی و Extract خودکار فایل در Dockerfile از کدام دستور استفاده می‌شود؟

    پاسخ صحیح: دستور ADD.

    ADD آرشیو tar محلی را Extract می‌کند؛ برای کپی ساده بهتر است از COPY استفاده شود.

  12. اگر Image فاقد CMD و ENTRYPOINT باشد، آیا می‌توان Container آن را فعال نگه داشت؟

    پاسخ صحیح: بله؛ می‌توان هنگام docker run فرمانی طولانی‌مدت مانند sleep ارائه کرد.

    عمر Container به Process اصلی آن وابسته است؛ sleep infinity یک Process طولانی‌مدت ایجاد می‌کند. 

    docker run image-name sleep infinity
