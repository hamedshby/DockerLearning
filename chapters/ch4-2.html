دستور COPY

دستور COPY فایل‌ها و پوشه‌ها را از سیستم میزبان به داخل Docker Image منتقل می‌کند.

نکته

COPY فقط فایل‌هایی را می‌تواند کپی کند که داخل Build Context قرار داشته باشند.

Syntax


COPY <source> <destination>
نمونه 

COPY . .

COPY appsettings.json .

COPY publish/ /app/

COPY *.csproj .

مثال


FROM mcr.microsoft.com/dotnet/sdk:9.0

WORKDIR /app

COPY . .
در این مثال تمام فایل‌های پروژه داخل مسیر /app کپی می‌شوند.

کپی پوشه 


COPY publish/ /app/
نتیجه 
Host

publish/

│

├── Shop.dll

├── appsettings.json

└── web.config

        │

        ▼

Container

/app

│

├── Shop.dll

├── appsettings.json

└── web.config

کپی فایل 


COPY appsettings.json .
یا 

COPY Program.cs /src/

کپی چند فایل 


COPY *.csproj .
یا 

COPY ["Shop.API.csproj", "./"]
این روش معمولاً در پروژه‌های ASP.NET Core استفاده می‌شود.

COPY و Build Cache

دستور COPY روی Docker Cache تأثیر زیادی دارد.

نمونه نامناسب 

COPY . .

RUN dotnet restore
با هر تغییر کوچک، Cache از بین می‌رود. نمونه مناسب 

COPY *.csproj .

RUN dotnet restore

COPY . .
در این حالت اگر فقط فایل‌های C# تغییر کنند، مرحله Restore دوباره اجرا نمی‌شود.
Best Practice

ابتدا فایل‌های پروژه (.csproj) را Copy کنید و سپس دستور Restore را اجرا کنید.

Best Practices

  • از COPY به جای ADD استفاده کنید.
  • از فایل .dockerignore استفاده کنید.
  • ابتدا فایل‌های پروژه را Copy کنید.
  • فقط فایل‌های موردنیاز را منتقل کنید.
اشتباهات رایج
  • COPY کردن کل پروژه بدون .dockerignore
  • قرار دادن COPY قبل از Restore
  • کپی فایل‌های غیرضروری

دستور ADD

دستور ADD عملکردی مشابه COPY دارد اما قابلیت‌های بیشتری نیز ارائه می‌دهد.

به طور کلی Docker پیشنهاد می‌کند در اکثر مواقع از COPY استفاده کنید و تنها در شرایط خاص از ADD بهره ببرید.

Syntax 


ADD <source> <destination>
نمونه 

ADD website.zip /app

ADD https://example.com/file.txt /app

ویژگی‌های ADD

قابلیت توضیح
کپی فایل مانند COPY
Extract فایل فشرده بله
دانلود از URL بله

استخراج فایل فشرده 


ADD website.tar.gz /app
Docker فایل را به صورت خودکار Extract می‌کند. نتیجه 
website.tar.gz

        │

        ▼

/app

│

├── index.html

├── css

└── js

دانلود فایل از اینترنت 


ADD https://example.com/config.json /app/
Docker فایل را دانلود می‌کند.
هشدار

استفاده از URL داخل Dockerfile باعث کاهش قابلیت تکرار Build می‌شود و معمولاً پیشنهاد نمی‌شود.

مقایسه COPY و ADD

ویژگی COPY ADD
کپی فایل ✔ ✔
کپی پوشه ✔ ✔
Extract فایل فشرده ✖ ✔
دانلود URL ✖ ✔
پیشنهاد Docker ✔ فقط در شرایط خاص
توصیه Docker

اگر فقط قصد کپی کردن فایل‌ها را دارید، همیشه از دستور COPY استفاده کنید. از ADD تنها زمانی استفاده کنید که به قابلیت Extract فایل‌های فشرده یا دانلود فایل از URL نیاز داشته باشید. 

                 Dockerfile

                     │

          ┌──────────┴──────────┐

          ▼                     ▼

       COPY                  ADD

          │                     │

   Copy Files          Copy + Extract + URL

در این آزمایش یاد گرفتید چگونه فایل‌ها و پوشه‌ها را با دستور COPY داخل Docker Image کپی کنید، تفاوت COPY و ADD را درک کنید و بهترین روش استفاده از هر کدام را بیاموزید. در اکثر پروژه‌های واقعی، دستور COPY انتخاب اصلی توسعه‌دهندگان است.
