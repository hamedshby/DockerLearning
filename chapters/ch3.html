Docker Container چیست؟

Docker Container نمونه‌ای در حال اجرا از یک Docker Image است.

هر Container محیطی ایزوله برای اجرای برنامه ایجاد می‌کند.

نکته

از یک Docker Image می‌توان چندین Container ساخت.

چرخه زندگی Docker Container

هر Docker Container دارای چرخه زندگی مشخصی است.

State توضیح
Created ساخته شده ولی اجرا نشده است.
Running برنامه در حال اجرا است.
Paused اجرای برنامه متوقف شده است.
Stopped متوقف شده است.
Deleted حذف شده است.

ایجاد اولین Container

اجرای اولین Container 

docker run hello-world

این ساده‌ترین دستور برای اجرای اولین Container است.

اجرای Nginx 

docker run nginx

این دستور Container را در حالت Foreground اجرا می‌کند.

اجرای Container در پس‌زمینه 

docker run -d nginx

با گزینه -d، Container در پس‌زمینه اجرا می‌شود.

گزینه‌های مهم docker run

Option کاربرد
-d اجرای در پس‌زمینه
-it ترمینال تعاملی
--name تعیین نام
-p نگاشت پورت
-e متغیر محیطی
-v اتصال Volume
--rm حذف خودکار

مشاهده Containerها

Containerهای در حال اجرا 

docker ps
نمونه خروجی 
CONTAINER ID   IMAGE     STATUS

8c45a9f2       nginx     Up 5 minutes

نمایش تمام Containerها 

docker ps -a

این دستور تمام Containerها را نمایش می‌دهد.

مدیریت Containerها

Stop

docker stop my-nginx

Start

docker start my-nginx

Restart

docker restart my-nginx

Pause

docker pause my-nginx

Unpause

docker unpause my-nginx

Kill

docker kill my-nginx
نکته

دستور stop امن‌تر از kill است.

حذف Container

Remove

docker rm my-nginx

Force Remove

docker rm -f my-nginx

حذف تمام Containerهای متوقف شده

docker container prune
هشدار

قبل از اجرای این دستور از عدم نیاز به Containerها مطمئن شوید.

گام ۳: مشاهده Container

docker ps

گام ۴: توقف Container

گام ۵: اجرای مجدد

سؤالات تستی Docker Container

با این سؤالات، مفاهیم اصلی ساخت و مدیریت Containerها را مرور کنید.

  1. Docker Container چیست؟

    1. یک Registry خصوصی
    2. یک نمونهٔ اجرایی از Docker Image
    3. یک فایل Dockerfile
    4. یک سیستم‌عامل کامل

    پاسخ صحیح: گزینهٔ ۲ — Container نمونه‌ای ساخته‌شده یا در حال اجرا از یک Image است.

  2. کدام دستور یک Container جدید را ایجاد و اجرا می‌کند؟

    1. docker start
    2. docker build
    3. docker run
    4. docker pull

    پاسخ صحیح: گزینهٔ ۳ — docker run یک Container را از روی Image ایجاد و سپس اجرا می‌کند.

  3. گزینهٔ -d در دستور docker run چه کاری انجام می‌دهد؟

    1. Container را در پس‌زمینه اجرا می‌کند
    2. Container را حذف می‌کند
    3. Image را دانلود می‌کند
    4. Volume ایجاد می‌کند

    پاسخ صحیح: گزینهٔ ۱ — -d مخفف detached است و Container را در پس‌زمینه اجرا می‌کند.

  4. کدام دستور تمام Containerها، حتی موارد متوقف‌شده را نمایش می‌دهد؟

    1. docker ps
    2. docker ps -a
    3. docker images
    4. docker inspect -a

    پاسخ صحیح: گزینهٔ ۲ — docker ps -a هم Containerهای فعال و هم متوقف‌شده را نشان می‌دهد.

  5. در -p 8080:80 عدد 8080 نشان‌دهندهٔ چیست؟

    1. پورت داخل Container
    2. پورت سیستم میزبان
    3. شناسهٔ Container
    4. پورت Docker Registry

    پاسخ صحیح: گزینهٔ ۲ — پورت 8080 میزبان به پورت 80 داخل Container نگاشت می‌شود.

  6. تفاوت اصلی docker stop و docker kill چیست؟

    1. هیچ تفاوتی ندارند
    2. stop برای Image و kill برای Container است
    3. stop ابتدا فرصت خاتمهٔ امن می‌دهد، اما kill فرایند را فوراً متوقف می‌کند
    4. kill فقط Container متوقف‌شده را اجرا می‌کند

    پاسخ صحیح: گزینهٔ ۳ — stop ابتدا SIGTERM می‌فرستد، ولی kill به‌صورت پیش‌فرض توقف فوری انجام می‌دهد.

  7. برای حذف تمام Containerهای متوقف‌شده از کدام دستور استفاده می‌شود؟

    1. docker container prune
    2. docker image prune
    3. docker system stop
    4. docker rm

    پاسخ صحیح: گزینهٔ ۱ — docker container prune همهٔ Containerهای متوقف‌شده را پاک می‌کند.
