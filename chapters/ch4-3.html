دستور RUN

دستور RUN برای اجرای دستورات هنگام ساخت Docker Image استفاده می‌شود.

نکته

RUN فقط در زمان Build اجرا می‌شود، نه هنگام اجرای Container.

زمان اجرای RUN 

Dockerfile

     │

docker build

     │

RUN apt-get update

RUN apt-get install nginx

     │

Docker Image

     │

docker run

     ▼

Container

تمام دستورات RUN قبل از ساخته شدن Image اجرا می‌شوند.

Syntax

Shell Form


RUN apt-get update

Exec Form


RUN ["apt-get","update"]
نکته

در اکثر Dockerfileها از Shell Form استفاده می‌شود.

مثال‌های متداول

بروزرسانی Packageها


RUN apt-get update

نصب نرم‌افزار


RUN apt-get install -y curl

ساخت پوشه


RUN mkdir /app

ایجاد فایل


RUN touch version.txt

تغییر Permission


RUN chmod +x start.sh

Restore پروژه دات‌نت


RUN dotnet restore

Publish پروژه


RUN dotnet publish -c Release -o /publish

چند دستور RUN

نمونه 

RUN apt-get update

RUN apt-get install -y curl

RUN apt-get install -y git
هر RUN یک Layer جدید ایجاد می‌کند.

Layer 1

ترکیب دستورات RUN

نمونه بهتر 

RUN apt-get update && \
    apt-get install -y \
    curl \
    git \
    wget

در این حالت فقط یک Layer ساخته می‌شود.

RUN و Build Cache

هر RUN یک Layer ایجاد می‌کند. اگر دستور تغییر نکند، Docker از Cache استفاده می‌کند. 

RUN apt-get update

        │

Layer Cached

        │

RUN apt-get install curl

        │

Layer Cached

        │

RUN dotnet publish

        │

Rebuild

Best Practices

  • چند دستور را در یک RUN ترکیب کنید.
  • پس از نصب Packageها Cache را حذف کنید.
  • از && استفاده کنید.
  • تعداد Layerها را کاهش دهید.
نمونه حرفه‌ای 

RUN apt-get update && \
    apt-get install -y curl && \
    rm -rf /var/lib/apt/lists/*
این روش باعث کاهش حجم Image می‌شود.

اشتباهات رایج

اشتباه روش صحیح 

RUN apt-get update

RUN apt-get install curl


RUN apt-get update && \
    apt-get install -y curl
پاک نکردن Cache حذف /var/lib/apt/lists
استفاده از RUN زیاد ترکیب دستورات

RUN و CMD

RUN CMD
هنگام Build اجرا می‌شود. هنگام اجرای Container اجرا می‌شود.
Layer جدید ایجاد می‌کند. Layer ایجاد نمی‌کند.
نتیجه داخل Image ذخیره می‌شود. فقط برنامه را اجرا می‌کند.

نمونه واقعی ASP.NET Core 


FROM mcr.microsoft.com/dotnet/sdk:9.0

WORKDIR /src

COPY *.csproj .

RUN dotnet restore

COPY . .

RUN dotnet publish -c Release -o /publish
در این Dockerfile
  • Restore هنگام Build انجام می‌شود.
  • Publish هنگام Build انجام می‌شود.
  • نتیجه داخل Image ذخیره می‌شود.
