# طراحی استفاده آفلاین از فونت Estedad

## هدف

فونت فارسی رابط کتاب Docker با Estedad جایگزین شود و سایت بدون اتصال اینترنت همان ظاهر را حفظ کند.

## طراحی

- نسخه متغیر و فشرده WOFF2 فونت Estedad در `assets/fonts` نگه‌داری می‌شود.
- یک قانون `@font-face` در ابتدای `style.css` وزن‌های 100 تا 900 را به فایل محلی متصل می‌کند.
- متغیر `--font-fa` ابتدا Estedad و سپس Tahoma و sans-serif را به‌عنوان fallback خواهد داشت.
- فونت انگلیسی و فونت monospace بلوک‌های کد تغییر نمی‌کنند.
- هیچ CDN، `@import` اینترنتی یا درخواست شبکه‌ای هنگام اجرای صفحه استفاده نمی‌شود.

## بررسی پذیرش

- فایل فونت از یک مسیر نسبی محلی بارگذاری شود.
- صفحه در حالت آفلاین از Estedad استفاده کند.
- وزن‌های عادی، نیمه‌ضخیم و ضخیم مورد استفاده رابط به‌درستی نمایش داده شوند.
- چیدمان فارسی RTL، محتوای انگلیسی و بلوک‌های کد بدون تغییر عملکردی باقی بمانند.
